# Good Times

An interval timer app built for iPhone, developed with Claude Code and React.

## What it does

- Create custom interval timers with multiple timed segments
- Save and manage timers by name
- Play timers full-screen with audio beeps between intervals
- Drag and drop to reorder intervals

## Tech stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Development

Requires Node.js and npm.

```sh
# Clone the repo
git clone https://github.com/MadsTagel/good-times.git

# Navigate into the project
cd good-times

# Install dependencies
npm install

# Start the dev server
npm run dev
```

Then open `http://localhost:8080` in your browser.

## Deployment

Connect the repo to [Vercel](https://vercel.com) for automatic deploys on every push.
